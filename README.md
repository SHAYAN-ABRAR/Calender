# My Personal Calendar — CSS Grid Month View

A clean monthly calendar layout built with **CSS Grid**, written in pure HTML and CSS.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit%20site-14B8A6?style=for-the-badge&logo=githubpages&logoColor=white)](https://shayan-abrar.github.io/Calender/calender) <!-- live-demo -->

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css&logoColor=white)

![Calendar month view](screenshots/preview.png)

## Features

- **7-column grid** (`grid-template-columns: repeat(7, 1fr)`) with weekday headers from Sunday to Saturday
- **Weekend highlight:** Friday and Saturday, the weekend in Bangladesh, are shown in red
- **Full month view:** dates from the previous and next months fill the first and last rows
- **Consistent spacing** using `row-gap` and `column-gap`, with flexbox-centered date cells

## Run Locally

```bash
git clone https://github.com/SHAYAN-ABRAR/Calender.git
cd Calender
# Open calender.html in a browser
```
